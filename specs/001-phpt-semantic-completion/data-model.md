# Data Model: phpt 语义完备主线（Phase 1）

本 feature 的「数据」是验收账本体系——七个实体全部为文件形态、git 或 tmp 管理。关系图：**基线分片**与**登记条目**汇入**判定命令**作差；**分诊报表**是批次的加工现场记录。

## E1 失败基线分片（Baseline Shard）

- **代表**: 某验收目录「当前已知失败用例集」——只收缩永不增长的事实快照。
- **字段**: `dir_id`（扁平目录标识，如 `zend-type_declarations`/`std`/`ext-dom`）；行集（`test <file>.phpt (Module.GN)`，沿用现行格式）。
- **来源**: `scripts/gate.sh --record [dirs]` 从绿非 phpt 套件后的运行录制。
- **约束**: 仅允许 `comm -13` 语义的收缩；分片按字典序 concat 必须等于全量失败清单（gate 自检）。
- **生命周期**: 首录（新目录纳入）→ 随批次单调收缩 → 归零或只剩豁免对应项。

## E2 豁免登记条目（Exempt Entry）— 终态

- **代表**: 「不追」的结论性决定。
- **字段**: 用例级 `用例路径 | 理由 | 解除条件`；目录级 `目录 id | 理由 | 解除条件`（16 扩展 + OPcache + FFI C 编译类 + intl 子集外 + gd 图像生成类）。
- **约束**: 每条必有理由与解除条件（豁免=待命，不是删除）；机器可读行格式见 contracts/baseline-formats.md。
- **生命周期**: 登记后长期有效；解除条件触发时移出并转入清偿批次。

## E3 顺延登记条目（Deferred Entry）— 临时态

- **代表**: 2h 时间盒超时的待办或深度工程拆出的里程碑。
- **字段**: `根因描述 | 登记日期 | 再入条件`；深度工程类另挂独立里程碑标识。
- **约束**: 相出口盘点（修复或转豁免，无第三态）；**不计入冻结达标**（criterion freeze 模式只认豁免集）。
- **生命周期**: 登记 → 再入条件满足时回到批次 → 清偿或转豁免。

## E4 目录映射条目（Gate Map Entry）

- **代表**: 「改动文件 → 需比对的基线分片」的守门规则。
- **字段**: 文件 glob 模式 → `ALL` | 目录 id 列表；注释理由。
- **约束**: 引擎核心路径 → `ALL`；**未命中 → `ALL`**（fail-safe，Q2 决议）；表随批次演化的变更走正常 commit。
- **生命周期**: R4 建立 → 批次中按新增目录/新增模块路径增改。

## E5 分诊报表（Triage Report）

- **代表**: 一批纳入时的失败全景加工记录。
- **字段**: 目录 id、批次号、初始失败数、按 `class=` 聚类的失败组、每组三选一处置（修复/豁免/顺延）。
- **约束**: **计数守恒**（SC-007）：`修复数 + 豁免数 + 顺延数 = 初始失败数`，随 commit 归档。
- **生命周期**: 批次开始生成 → 批次收尾计数闭合 → 归档不动。

## E6 环境不可得追踪项（Env-Blocked Case）

- **代表**: 因外部环境缺失而无法判定的用例（Q3 决议：临时态非终态）。
- **字段**: 用例路径、缺失环境（mysql/ftp-server/network）、登记日期。
- **约束**: 环境可得时（相收尾/全量通道）强制复跑并按语义失败重新分诊；复跑义务由全量通道的比对自动执行——环境恢复后这些用例重新出现在失败清单即触发。
- **生命周期**: 标记 → 环境恢复复跑 → 转入正常三选一。

## E7 漂移登记项（Drift Entry）

- **代表**: 版本对齐（8.4.25/8.4.17）重录时发现的与旧记录不一致用例。
- **字段**: 用例路径、差异类型（expect 文本/SKIPIF 行为）、处置。
- **约束**: 不静默改判——每条单列；R5 一次性产出后冻结。

## 实体关系

```text
分诊报表(E5) ──产出──▶ 豁免条目(E2) / 顺延条目(E3) / 修复(改代码→基线收缩)
基线分片(E1) ──比对──▶ gate.sh（目录通道/全量通道）
E2 ∪ E3 ──作差──▶ criterion.sh（相出口模式）；E2 单独 ──作差──▶ criterion.sh（冻结模式）
环境不可得(E6) ──环境恢复──▶ 回到 E5 重分诊
映射表(E4) ──选择──▶ gate.sh 目录通道要跑哪些 E1 分片
```
